# AGENTS.md — meowtrix / Meowtrix-0.8B

Guidance for contributors and coding agents working in this repository.

## Project overview

Open-source AI research & post-training repo. **Meowtrix-0.8B** is a
0.8B-parameter causal LM built on `Qwen/Qwen3.5-0.8B` (24-layer hybrid stack:
each 4-layer cycle = 3x Gated DeltaNet + 1x GQA) with:

- **Recurrent depth / test-time latent compute** — layers 8–15 (config:
  `recurrent_start=8`, `recurrent_end=16`, end-exclusive) execute `num_loops`
  times (default 3, `max_loops=8`). Loop 1 writes KV/DeltaNet caches;
  loops 2..K refine hidden states with cache writes off and inject deltas
  through the learnable `loop_gates` vector (init 0.05).
- **Thinking-aware abliteration** — refusal direction estimated from residual
  stream at layers 13–18 (inclusive) with `enable_thinking=True`, then
  projected out of `o_proj`/`out_proj`/`down_proj` weights.
- **Two-stage LoRA post-training** — stage 1 annealing (latent alignment),
  stage 2 persona + compact `<think>` CoT. bf16, `target_modules: all-linear`,
  `modules_to_save: [loop_gates]`.
- **HF export via `auto_map`** — `scripts/export_hf.py` writes config.json +
  the two `*_meowtrix.py` remote-code files next to the weights.

## Environment

- Python env is managed by **uv** (`uv sync`, lockfile `uv.lock` is committed).
  `.python-version` pins 3.12 for torch/transformers compatibility.
- `just` recipes wrap every workflow: `just --list`.
- Do not introduce a second package manager (no requirements.txt, no conda).
- Cross-platform: code must stay backend-agnostic (`device: auto` →
  `cuda`/`mps`/`cpu`). No CUDA-only APIs, no vendor inference frameworks.

## Conventions

- Docs/comments/commit messages in **English**; identifiers in English.
  Release notes ship bilingual (zh-CN + en).
- **Conventional Commits 1.0.0** — `type(scope): description`, English,
  one logical change per commit. `feat`/`fix`/`docs`/`refactor`/`test`/`chore`.
- **No AI-tool attribution** in commits, PRs, issues, comments, or docs
  (no `Co-Authored-By` bots, no "generated by" footers) — commit author is
  the human contributor only.
- Keep diffs focused: no unrelated refactors, dependency swaps, or reformat.
- When changing behavior, public interfaces, or configs, update README /
  AGENTS.md / examples in the same commit.
- Never commit weights, datasets, checkpoints, or secrets — they are
  gitignored; full artifacts live on Hugging Face.

## Known open decisions (待决定)

- Loop-gate mixing form: currently `h += g·(refined − h)` per extra loop;
  alternatives (full gated replacement, per-layer gates) are open for ablation.
- Whether refinement loops should attend over the loop-1 KV cache (current
  choice: read yes, write no) vs. fully detached latent passes.
- Recurrent span boundary (8–16) vs. shifting it across the 4-layer cycles.
- Whether `num_loops` during training should be fixed, randomized per batch,
  or annealed.
- License choice before first public release.
